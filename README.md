# 💰 Python Expense Tracker

A simple **console-based Expense Tracker** developed using Python. This project helps users record and manage their daily expenses through an easy-to-use menu-driven interface.

## 🚀 Features

* ➕ Add a new expense
* 📋 View all recorded expenses
* 💰 Calculate total expenses
* 📅 Store the date of each expense
* 🏷️ Categorize expenses
* 📝 Add a description for each expense
* 🚪 Exit the application

## 🛠️ Technologies & Concepts Used

* Python 3
* Lists
* Dictionaries
* `while` loops
* `for` loops
* `if-elif-else` statements
* User input
* Basic arithmetic
* f-strings

## ⚙️ How It Works

The program displays a menu with four options:

```text
1. Add Expense
2. View All Expenses
3. View Total Expenses
4. Exit
```

When adding an expense, the user enters the **date, category, description, and amount**. The details are stored in a dictionary and added to a list.

The user can then view all saved expenses or calculate the total amount spent.

## ▶️ How to Run

Make sure Python 3 is installed.

Run the program using:

```bash
python expense_tracker.py
```

## 🎯 Purpose

This project was created to practice fundamental Python concepts and understand how lists, dictionaries, loops, and conditional statements can be used together to build a practical application.
