# Project Statement

## Python Console Expense Tracker

The **Python Console Expense Tracker** is a menu-driven Python application developed to provide a simple method for recording and monitoring daily expenses. The application allows users to enter the date, category, description, and amount of an expense and stores the information for use during the current program session.

The system provides three main operations: adding a new expense, viewing all recorded expenses, and calculating the total amount spent. A fourth option allows the user to exit the application.

The project is designed using fundamental Python programming concepts, including **lists, dictionaries, loops, conditional statements, user input, arithmetic operations, and formatted output**. Each expense is stored as a dictionary, while a list is used to maintain multiple expense records.

The primary objective of this project is to demonstrate how basic programming concepts can be applied to develop a practical real-world application. It also helps develop logical thinking, data organization, and problem-solving skills.

### Key Objectives

* Record daily expense information.
* Organize expenses using Python data structures.
* Display all recorded expenses.
* Calculate total expenses automatically.
* Implement a simple menu-driven interface.
* Apply fundamental Python programming concepts to a practical problem.

### Current Scope

The current version is a **console-based application** and stores expense information temporarily during program execution. It focuses on basic expense recording and calculation without permanent data storage.

### Future Scope

The project can be extended with permanent file or database storage, expense editing and deletion, category-wise analysis, monthly reports, search functionality, and a graphical user interface.
